# UpperComputer · 发布仓

本仓库**只存放上位机的发布产物**（Releases 页面的 zip 安装包），不含源码。

- 源码仓库私有（实验室内部）
- 下载：进入 [Releases](../../releases) 取最新版本的 zip，解压即用（自带 Qt 运行库与便携 g++ 工具链）
- 程序内「帮助 → 检查更新」也指向本仓库，会自动发现新版本
- Gitee 镜像：`gitee.com/sansan120712/car_sim-dist`（无 GitHub 网络时程序自动回退）
