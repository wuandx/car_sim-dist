# 功能指南 · 协议分析与信号源

调试陌生设备或没有下位机时的两组工具。

## 帧解码器（FrameDecoderWindow）

- 基于**可配置块描述**（FdBlock）的通用帧解码器：任意帧格式（不限于 V2）都能描述并实时解码
- 数据来自三通道的原始字节流（`rawChunkReceived`），与主解析链路并行、互不影响
- 适合：调试自定义协议、教学演示、验证下位机组帧

## 逻辑分析仪（LogicAnalyzerWindow + LogicTimingView)

- UART / I2C / SPI 总线协议解码：输入每字节一个采样的电平流，输出协议事件与时间波形
- 时序图支持缩放、游标测量

## 信号发生器（SignalGenDialog + 虚拟信号通道）

- 传输方式选 **「虚拟信号」**：内置多波形信号源（正弦/方波/扫频等）按真实 V2 遥测帧走完整链路
- 用途：无硬件时驱动示波器验证显示/滤波/FFT，或演示
- 信号源也可独立用于算法调试（`src/util/SignalGenerator`）

## 数字滤波与频谱

- `DigitalFilter`：示波器内置滤波（配合悬停读数对比滤波前后）
- `SpectrumAnalyzer`：示波器 FFT 模式后端（radix-2 + Hann 窗）
