# 功能指南 · 示波器与在线调参

## 多通道示波

打开 **示波** 窗口（工具栏或菜单），下位机遥测帧自动驱动波形：

- **时域波形**：多通道同屏、自动量程（恒定信号也能看到水平线）、悬停读数
- **FFT 频谱**：自写 radix-2 + Hann 窗，切模式即看频域
- **数字滤波**：内置滤波器处理后再显示
- **波形统计**：MAX / MIN / MEAN / RMS
- **CSV 导入**：回放历史数据

> 窗口内的 `帧: N`（读解析帧计数）才是遥测链路的真指标；主窗口底部 `帧数: N` 只计图像帧。

## 遥测数据约定

下位机每帧声明 `起始通道 + 通道数 + 采样类型`，多路信号可拆多帧分批发送（`start_channel` 标明落点），不必每帧带全部通道。采样类型：int16 / float32 / int32（值一律小端）。

## 在线调参

调参面板内嵌在示波窗口右侧：

1. 选择**通道号 + 数据类型**（int8/uint8/int16/uint16/int32/uint32/float32），输入值
2. 下发 → 走 Command 帧（二进制 payload，程序自动封帧头，**不要自己加帧头**）
3. 下位机写成功后回 **Response 帧**，面板绿闪确认；失败红闪并显示状态码（通道越界 / 值超限 / 类型不支持 / CRC 错误）

配合示波器即可闭环：改参数 → 看波形变化，全程不重启。
