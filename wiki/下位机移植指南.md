# 下位机移植指南

> 仓库自带纯 C99、零依赖协议库：[`docs/mcu_port/`](https://github.com/wuandx/car_sim/tree/master/docs/mcu_port)。
> 已验证平台：Infineon AURIX、逐飞（Seekfree）库、STM32/GD32 通用 ARM。

## 移植三步

**1. 拷两个文件进工程**

`uppercomputer_frame.h` + `uppercomputer_frame.c`，无任何外部依赖。

**2. 实现两个发送函数**（唯一的硬件相关部分）

```c
// 例: AURIX ASCLIN
void uc_uart_putc(uint8_t b) {
    while (ASC0_TX_FIFO_FULL()) { }
    ASC0_TXD = b;
}
void uc_uart_write(const uint8_t *data, uint32_t len) {
    for (uint32_t i = 0; i < len; ++i) uc_uart_putc(data[i]);
}
```

> 使用逐飞库的工程**不用实现**：库头文件已把发送接口映射到 `uart_write_byte(UART_0, ...)`。
> 非逐飞平台定义 `UC_NO_ZF_HEADFILE` 宏后按上面方式自实现（参考 `user_port.c`）。

**3. 调用便捷函数发数据**

```c
uc_send_image_frame(h, w, gray);                    // 灰度图传
uc_send_telemetry_frame(0, 4, UC_SAMPLE_INT16,      // 4 通道 int16 遥测
                        (const uint8_t*)adc, sizeof(adc));
uc_send_command(cmd, len);                          // 收到的命令转发/自定义
uc_send_heartbeat();                                // 保活
```

接收方向：把串口 RX 字节逐个喂给 `uc_rx_feed()`，完整帧回调 `uc_rx_handler(type, payload, len)`——调参命令在此解析回显。

## 移植须知（踩过的坑）

| 事项 | 说明 |
|------|------|
| **CRC 必须对** | CRC-16/CCITT-FALSE（poly 0x1021 / init 0xFFFF / 不反射），自检 `"123456789" → 0x29B1`；不对则上位机全部丢帧 |
| 发送原子性 | 一帧字节须连续发出，不能被其他发送源交错（发送期间关中断抢占或做流控） |
| 宽高非零 | Image 帧 height/width 不能为 0 |
| 单帧上限 | payload ≤ 16 MB；图像建议 ≤ 320×240 灰度 |
| 无堆可用 | 图像帧流式逐字节发送 + 增量 CRC，无需大缓冲，适合裸机 |

## 端到端验证

`tests/mcu_frame_test`：MCU 组帧 ↔ 上位机真实解析器互测（CRC/帧头/子头/分片/抗干扰重同步），Windows 与 Linux 均 ALL PASS。移植后跑一遍固件侧自检（`selfcheck.c`）+ 上位机 `CRC` 计数为 0 增长，即可确认打通。
