# 开发与测试

> 面向贡献者/AI 编程助手。仓库内 [`AGENTS.md`](https://github.com/wuandx/car_sim/blob/master/AGENTS.md) 是给 AI 助手的入口（硬约束清单），本页是补充导读。

## 仓库结构

```
src/
├─ protocol/     帧协议: FrameParser(V2状态机) FrameDecoder(通用块解码) LogicDecoder CRC16
├─ serial/       SerialMgr 串口封装(接收在工作线程)
├─ transport/    CommMgr 统一调度 + WifiMgr + BluetoothMgr
├─ plugin/       PluginManager 算法插件编译加载
├─ core/         ImageSaver VideoRecorder AviReader Settings AlgorithmStore Updater
├─ ui/           MainWindow ImageView GalleryPanel ScopeWindow CodeEditor
│                ParamTuningPanel SignalGenDialog FrameDecoderWindow LogicAnalyzerWindow
└─ util/         SignalGenerator DigitalFilter SpectrumAnalyzer
docs/            协议规范(protocol-v2.md) MCU移植(mcu_port/) 设计文档 archive/(历史)
tests/           conn_verify(通信回环) mcu_frame_test(协议端到端)
tools/           simulate_device.py 虚拟设备模拟器
```

深层导读：`docs/code-guide.md`；整体设计：`docs/project-summary.md`。

## 平台矩阵

| 平台 | 角色 | 产物目录 |
|------|------|----------|
| Windows | 发布 | `bin/` `build/` `build_qmake/` |
| Linux | 开发 | `bin_linux/` `build_linux/` |

两边目录**绝不互写**（`.pro` 平台作用域保证）。`bin/mingw64/` 是插件热编译的便携 g++ 兜底，不是垃圾。

## 测试基线

| 测试 | 覆盖 | 基线 |
|------|------|------|
| `tests/mcu_frame_test` | MCU 组帧 ↔ 上位机解析端到端（CRC/子头/分片/重同步） | ALL PASS（Win + Linux） |
| `tests/conn_verify` | 7 阶段通信回环（WiFi TCP/UDP、Virtual、Serial、Bluetooth 优雅失败） | **19 PASS / 0 FAIL**（Win 2026-08-31 / Linux 2026-09-04） |

**改了通信层（SerialMgr/WifiMgr/BluetoothMgr/CommMgr/FrameParser/CRC16）→ 必须重跑 conn_verify**，不得回归。

## 文档维护约定（防漂移）

- **协议唯一真值**：`docs/protocol-v2.md`。其他文档（含本 wiki）只写摘要并指向它
- 主题皮肤：`style_template.qss` + `gen_all_themes.py` 单一真值，改色板三处同步（脚本 PALETTES、`theme_palette.h`、`applyTheme`）
- 本 wiki 是**用户层**文档；仓库 `docs/` 是**开发层**文档；改动功能时两层都要过一眼

## 已知设计取舍

- 帧解析在后台线程；图像构造、录像 JPEG 编码写盘仍在 GUI 线程（高分辨率高频图传可能卡顿，计划迁移）
- 截图保存原始帧而非算法结果帧
- Linux 蓝牙置灰待 BlueZ 真机实测
