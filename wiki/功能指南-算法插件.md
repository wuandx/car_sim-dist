# 功能指南 · C++ 算法插件

> 特性：写 C++ 图像算法 → 一键编译成动态库 → 热加载到图传链路，**全程不重启程序**。

## 快速上手

1. 打开 **算法窗口**（UserCodeWindow），点「新建」——提供代码模板；示例算法存放于 exe 同级 `algorithms/` 目录（自适应阈值、大津法、Sobel 边缘、亮度、对比度、8 邻域边线跟踪共 6 个）
2. 实现 C 接口（`extern "C"`）：

```cpp
// 最小示例：二值化
extern "C" int pluginProcess(const unsigned char* src, int w, int h,
                             unsigned char* dst) {
    for (int i = 0; i < w * h; ++i)
        dst[i] = src[i] > 128 ? 255 : 0;
    return 0;
}
```

3. 点 **编译运行**：程序异步调用 `g++ -shared -O2 -std=c++17 -fPIC` 编译（30 秒超时保护）
4. 编译成功即热加载，图传每帧自动过算法，**结果视图**叠加坐标点显示

## 编译器从哪来

`PluginManager` 按顺序探测 64 位 g++：

1. `D:\Qt\Tools\mingw810_64\bin\g++.exe` 等常见安装位置（Windows）
2. exe 同级 `mingw64/bin/g++.exe`（便携部署，发布包自带）
3. PATH 中的 `g++`（Linux 天然命中）

每个候选都会用 `-dumpmachine` 验证是 64 位（输出含 `x86_64`）。

## 常见问题

| 现象 | 原因 |
|------|------|
| 加载报 `ERROR_BAD_EXE_FORMAT (0xC1)` | 主程序与插件位数不一致（必须同为 64 位） |
| 找不到符号 | 接口没有 `extern "C"`（C++ 名字修饰导致） |
| 编译超时 | 30 秒保护触发，检查代码是否有死循环 |

Linux 上插件编译为 `.so`，Windows 为 `.dll`，行为一致。
