# 快速开始

> 目标：10 分钟内让下位机的图像和波形出现在屏幕上。

## 1. 获取程序

- **Windows**：从 [Releases](https://github.com/wuandx/car_sim/releases) 下载 zip 解压，双击 `UpperComputer.exe`（自带全部 Qt 运行库，无需安装任何依赖）
- **Linux**：见 [构建指南](构建指南.md)，编译后 `./run_linux.sh`

## 2. 连接下位机

1. 在顶部通信栏选择传输方式：**USB / WiFi-Client / WiFi-Server / WiFi-UDP / 蓝牙**
2. 按所选方式填写配置：

| 方式 | 需要填 | 典型值 |
|------|--------|--------|
| USB | 串口 + 波特率 | COM3 / 921600 |
| WiFi-Client | 下位机 IP + 端口 | 192.168.4.1:8080 |
| WiFi-Server | 本机监听端口 | 8080 |
| WiFi-UDP | 本机绑定端口 | 8080 |

3. 点击 **连接**，状态灯变绿即成功

> 💡 没有下位机也想先体验？选 **「虚拟信号」** 通道——内置信号发生器会生成演示波形驱动示波器。

## 3. 看到画面和波形

- **图传**：协议下拉选 `V2 协议`，下位机发图后主视图实时刷新；**点击主视图任意位置即保存 PNG 截图**（存于 exe 同级 `images/`，画廊面板可浏览）
- **示波**：打开 示波 窗口（工具栏或菜单），下位机发遥测帧后波形自动滚动；底部指标条 `TEL:N` 是遥测帧计数

## 4. 常用下一步

- 调参数 → [示波器与调参](功能指南-示波器与调参.md)
- 写图像算法 → [算法插件](功能指南-算法插件.md)

## 下位机需要发什么？

程序只认 **V2 帧协议**（6 字节帧头 + payload + CRC16）。如果你的固件还没实现，直接抄 [下位机移植指南](下位机移植指南.md)——两个 C 文件、实现两个发送函数就能通。
